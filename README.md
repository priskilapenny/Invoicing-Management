# Invoicing-Management-System
## Project Overview

This project documents the design and implementation of a relational database and REST API developed to support an invoicing system application backend for Accommodation and Property Rental.

The work covers database schema design, relationship implementation, SQL query development, and REST API development. The API endpoints were designed to provide data access and functionality for integration by other members of the development team.

## Project Background

This system is designed to integrate the utility recording process, cost calculation, up to invoice creation and delivery within a single centralized system. With meter data collection mechanisms directly connected to the system, all calculations can be performed automatically and more accurately. In addition, the system simplifies the billing process for residents, including those in different locations, with a more efficient and transparent workflow. This approach helps reduce calculation errors, speed up administrative processes, and improve ease in managing utility payments and tax reporting.
