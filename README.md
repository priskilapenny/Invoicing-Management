# Invoicing-Management-System
## Project Overview

This project documents the design and implementation of a relational database and REST API developed to support an invoicing system application backend for Accomodation and Property Rental.

The work covers database schema design, relationship implementation, SQL query development, and REST API development. The API endpoints were designed to provide data access and functionality for integration by other members of the development team.

## Project Scope

- Designed the relational database schema and Entity Relationship Diagram (ERD).
- Implemented database tables, relationships, keys, and constraints.
- Developed SQL queries to support application requirements.
- Built REST API endpoints to access and process database data.
- Prepared API endpoints for integration with the application backend.
- Documented the database structure, query logic, and API interfaces.
